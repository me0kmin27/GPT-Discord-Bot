설치된 discord-helper start는 봇만, discord-helper gui start는 GUI만 시작합니다. sudo 또는 helperbot 폴더의 python manage.py 직접 실행은 사용하지 마세요.

설치된 Python으로 python -m helperbot.manage overview를 실행할 수도 있습니다. 설치 경로와 config/data/unit 디렉터리를 먼저 확인하세요.

이 GUI의 접속 주소: http://127.0.0.1:{{ port }}. 원격 서버라면 로컬 PC에서 동일 포트 터널을 열고 이 주소를 사용하세요. USER@HOST는 실제 서버 계정으로 교체합니다.

ssh -N -L {{ port }}:127.0.0.1:{{ port }} USER@HOST

LAN 주소 접속이나 bind 변경만으로는 허용되지 않습니다. 공개 노출·자동 시작 설정은 별도 승인이 필요합니다.
